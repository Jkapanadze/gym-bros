# Rep Club

A small, playful shared gym calendar for three friends. It is a static site with no build step or dependencies.

## Run it

Open `index.html` in a browser, or serve this folder with any static file server.

## Features

- Monthly calendar with planned workout markers
- Add workouts and tap them to mark sessions complete
- Weekly three-session group goal
- Editable crew names
- Browser-local persistence using `localStorage`
- Responsive layout for phones and desktop

## GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In repository **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save. GitHub Pages will provide the published URL.

The current version stores changes in each visitor's browser. For friends to see the same calendar and check-ins, the app will need a shared backend or hosted database.
